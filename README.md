# BookClub
A book club mobile app developed with the Ionic Framework. The app provides an easy 
way to manage multiple book clubs, organize reading lists, track books and ratings, 
and schedule and keep notes about club meetings.

 ## To run
 * Clone this repository: `https://github.com/MelissaOBrienJC/BookClub.git`.
 * Run `npm install` from the project root.
 * If you do not have the ionic CLI installed run `npm install -g ionic`
 * Build the application with npm run build
